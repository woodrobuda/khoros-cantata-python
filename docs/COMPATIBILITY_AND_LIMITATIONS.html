Khoros/Cantata Python — Compatibility and Limitations

Release: Phase 22 / 0.22.0

Supported reconstructed areas

  • Cantata workspace parsing and native graph execution.
  • KForms/UIS semantic parsing from the recovered 154-pane corpus.
  • KDBM-compatible record reading.
  • VIFF reading and selected writing support.
  • Data Services object concepts needed by the recovered code.
  • Selected source-derived numerical behavior.

Known limitations

  • No runnable historical Khoros executable was available for the final audit.
  • Some historical sample-data distributions are missing.
  • Not every one of the 134 registered operator surfaces has direct behavioral proof.
  • Some specialized historical control-flow types and external connection cases need more evidence.
  • Historical GUI appearance is not reproduced by this Python core.

How to read the operator matrix

The matrix separates source evidence from behavioral evidence. This prevents a working Python function from being mistaken for proof of exact historical equivalence.
